Lu-Mi-Num Aluminum Miners Carbide Lamps - PowerPoint (3:4, 7.5 x 10 in)
=======================================================================

FILES
- LuMiNum_CarbideLamps.pptx  : the deck (1 slide). All copy is live text, border and
                               logos are native PowerPoint freeform shapes (vector),
                               lamp illustrations are transparent PNG cut from the scan.
- svg/border_unit.svg        : one repeat of the beaded border (source vector)
- svg/border_frame.svg       : full frame built by repeating the unit (<use>)
- svg/logo_luminum.svg       : cleaned-up LU-MI-NUM LAMP trade mark (source vector)

FONTS (all Google Fonts, SIL Open Font License) - install before opening
- Cormorant SC (Bold)                 : "Aluminum / Miners Carbide Lamps"
- Libre Caslon Text (Regular, Bold)   : headings, prices, large-lamp text
- Old Standard TT (Regular, Bold)     : small body text, specification lists
- Courier Prime (Regular)             : "Patented...", "West of Denver...", "For Superintendents..."
- Archivo Black                        : "No. 4-F" / "No. 4" / "No. 4-H"
  (logo letters are outlines, so the logo needs no font)
  https://fonts.google.com/specimen/Cormorant+SC
  https://fonts.google.com/specimen/Libre+Caslon+Text
  https://fonts.google.com/specimen/Old+Standard+TT
  https://fonts.google.com/specimen/Courier+Prime
  https://fonts.google.com/specimen/Archivo+Black
To keep the layout on other PCs: File > Options > Save > "Embed fonts in the file".

TEXT CORRECTIONS (vs. the original scan)
- "Alumnum Reflector" -> "Aluminum Reflector" (price table, No. 4 / 4-F)
- Line-end hyphenation of the original (pro-jects, Ex-tra, am-monia, descrip-tion,
  fea-tures) removed; text re-flows in the text boxes.
- Kept as printed (period spelling): Miners, Fibre, N. P., Monel, insures, ozs.
